# Midnight Files

Short vertical "strange history" films made entirely with code: the picture is drawn frame by frame in headless Chrome,
the score is synthesized with numpy, the narration is text-to-speech.

- `CLAUDE.md` is the production guide: rules, layout, and the step-by-step process.
- `kit/` is the shared engine and tools.
- `films/` holds one folder per film; `films/2026-11-20-black-friday/` is the worked example.
- `TOPICS.md` lists every film made.

Requirements: Python 3 with numpy, scipy, pillow and playwright, Google Chrome, ffmpeg, and the fonts Latin Modern Roman and Bitter.
