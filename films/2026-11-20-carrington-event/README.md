# The Carrington Event (first film, 58 s)

Archived exactly as it was made, before the shared `kit/` existed: this folder carries its own copy of the engine and tools.
To render it again: `npm install` here (d3-array and d3-geo for the globe), then `python3 shots.py`, `python3 audio.py`,
`python3 render.py 0 2 & python3 render.py 1 2 & wait` from inside this folder.
